# Fees 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The bursar's class-by-class « Contrôle des frais » list, recorded send-outs shown as « Renvoyé pour frais » in roll calls (never counted as absences), checkable return notes and checkable warnings to parents.

**Architecture:** Three new Ash resources in the `TeacherAssistant.Fees` domain (`FeeSendOut`, `ReturnNote`, `FeeWarning`) behind a new context module `TeacherAssistant.FeeControl`; one pure function added to `FeeBalance` for the per-fee overdue split; a new `AttendanceStatus` value `:sent_home` that the roll call pre-fills from the day's send-outs; the receipt check generalised to three paper kinds told apart by number prefix (R/A/V) and by a per-kind HMAC salt.

**Tech Stack:** Elixir, Phoenix 1.8 LiveView, Ash 3 + AshPostgres (attribute multitenancy), daisyUI/Tailwind v4, Gettext, EQRCode.

**Spec:** `docs/superpowers/specs/2026-10-21-fees-2-design.md` (builds on `docs/superpowers/specs/2026-10-19-fees-1-design.md`).

## Global Constraints

- Ash resources with attribute multitenancy on `workspace_id`; composite FKs `match_with: [workspace_id: :workspace_id]` (`match_type: :full` required, `:simple` + `on_delete: {:nilify, [:col]}` nullable).
- Migrations only via `mix ash.codegen fees_2` (answer rename prompts with `yes n |`); never hand-written.
- No bare `:atom` attributes: Ash enums only.
- Writes on the fees axis `{Checks.SchoolRole, any_of: :fees}` (head, vice principal, bursar); reads of `FeeSendOut` by any active member (teachers need it for roll call); notes and warnings read by the fees axis.
- `YearOpen` validation on every create/update of the new resources.
- « Today » is `TeacherAssistant.Academics.Reference.today/0`; tests run with the clock frozen at 2025-09-15.
- Gettext: French msgids, English translations filled, no `fuzzy` left in either `.po` (re-run `mix gettext.extract --merge` after `mix precommit` reformats).
- Screens gated by the `frais` module (`lib/teacher_assistant/modules.ex`); every new LiveView/controller action is listed there.
- Numbers: `A<start year>-000001` notes, `V<start year>-000001` warnings, per school per year, under `pg_advisory_xact_lock(hashtext("<kind>:ws:year"))` like receipts.
- Return notes never print an amount. The check page shows only what the paper prints.
- Work in a worktree under `.claude/worktrees/fees-2`, `MIX_TEST_PARTITION=3`, stage explicit paths, `mix precommit` before the last commit.

## Review Focus

1. **A payment recorded the same day after a send-out.** Expect: the send-out is lifted if the student is no longer behind; later roll calls show them normally. Test in Task 3.
2. **A combined course (several classes in one roll call).** Expect: sent-home students of every class in it are pre-filled. Test in Task 6.
3. **A crafted `"sent_home"` status posted by a teacher, or a teacher switching a sent-home student to absent.** Expect: ignored. Test in Task 6.
4. **A note whose « valable jusqu'au » is before its issue date or before today.** Expect: `{:error, :invalid_valid_until}`. Test in Task 4.
5. **A warning batch where some chosen students are not behind (paid since the page loaded).** Expect: they are skipped. An empty result is `{:error, :nothing_to_warn}`. Test in Task 5.
