# Glossary — Bilingual Controlled Vocabulary (FR ↔ EN)

The system is **officially bilingual**. Carry both labels for every domain concept; this glossary
is the canonical FR↔EN mapping for UI strings, data labels, and report templates.
Flags: ⚠️ = ambiguous / verify · 🟡 = varies by school/subject.
